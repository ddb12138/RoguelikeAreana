建议按以下顺序学习：

1. [公共实现与新增武器步骤](IMPLEMENTATION.md)：控制器、攻击实体、升级资源、信号链如何协作。
2. 对应武器页：先看简要说明与升级表，再对照核心 GDScript 和动画轨道。
3. [战斗实验场](../development/COMBAT_LAB.md)：屏蔽其他怪物和武器，按 U 实际观察每级变化。
4. [变种与更新记录](VARIANTS.md)：区分已经实现的变体和未来设想。

## 文档维护约定

新增或修改武器时，同一次改动同步维护本索引、对应武器页、升级表、变种记录及关联测试。每页至少包含：作用、默认参数来源、解锁条件、真实升级 ID／上限／公式、核心 GDScript 节选与解释、关键节点或动画轨道、变种状态、验证范围及已知限制。

代码块是源码节选，必须附源码链接。省略内容或教学伪代码要明确说明；不要复制整份脚本后不解释。公式里的 `n` 表示**该升级项的已选择次数**，不是玩家等级。

吸力 `suction_ability` 属于敌人能力，不在玩家可选武器池中；见 [宝箱怪](../monsters/MIMIC_CHEST.md)。
