美术素材主要看 CC0、CC-BY 等开放许可；代码主要看 MIT 等开源许可证。这里分别记录，避免把“免费下载”当成“可以任意修改、再分发”。

## 如何维护

后续本项目挑选、下载或替换资源时，在相应专题文档同步更新以下内容，不只粘贴网址：

1. 作品名称、作者、原始作品页、官方下载入口、核查日期。
2. 具体许可证及出处、署名要求、资源包中的额外声明。
3. 用途、素材规格、Godot 接入方式、对本项目画风和分辨率的适配判断。
4. 状态：`候选／已下载／已接入／已验证／弃用`；下载与运行验证分别记录。
5. 下载后补充实际文件名、SHA-256、本地路径、保留的许可证位置和修改说明。尚未下载时不猜测文件内容或兼容性。

推荐先把试选资源放到项目外的临时目录。选定后，仅将使用到的资源与许可记录纳入 `asserts/` 下合适的子目录，保留项目已有拼写。不要把整套示例工程直接复制进游戏。

这是随项目资源工作更新的目录，不设定定时抓取或自动下载任务。链接失效时保留记录并标记，找到作者的新地址后再替换。
